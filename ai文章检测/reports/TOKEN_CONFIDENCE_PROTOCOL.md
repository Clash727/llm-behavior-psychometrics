# Token 置信度基础实验协议

用户已授权启动，GPT-6-Luna high 实现，主代理验收。

冻结的原始 Qwen3-4B 参考语言模型对 human/machine 正文统一 teacher forcing 重打分，不使用当前分类 adapter，不生成新文本。token 的条件概率不是分类头输出的 machine 概率，也不是模型口头自报置信度。

先验证 shifted logits、padding、special token 和首 token 掩码；固定版本与精度，仅保留真实 token 的 log-probability 统计，不能称为完整词表分布熵。上下文上限 512，原始 train/dev 不变。缓存绑定模型版本、精度、数据哈希与特征定义，逐批记录进度，可安全续跑。

主实验：训练集拟合标准化与逻辑回归，dev 固定阈值 0.5；报告整体和短文宏 F1、综合分、人类误报、机器召回及领域和长度分组。以长度特征单独分类作为捷径对照。融合与泛化扩展待基础信号结果后再决定；不读取 locked_test 或官方 val。

真实 GPU 小样本通过主代理检查后才可正式提取。正式运行记录样本吞吐、预计完成时间、峰值显存和特征异常。所有已有分类模型与划分保留。
